# Scenario runs

Frozen records of scenario tests against specific commits. The answer files
are what the skill produced on that date; do not edit them to match later
versions of the skill. Re-run the prompts instead and add a new dated folder.

Each folder has a `GRADING.md` with the setup, the rubric, the defects found,
and the verdict. The prompts in `2026-10-04-scenarios/` are the ones to
re-run after changing the skill's decision rules.

The answer files keep the punctuation they were generated with, including em
dashes; they are records, not docs.
